### 1. LINK_EXTRACTOR_AGENT

**Función:** Extraer TODOS los dominios externos únicos de una página.

```python
# Implementación requerida:
import requests
from bs4 import BeautifulSoup
from urllib.parse import urlparse
import re

def extract_external_domains(source_url):
    """
    Extrae todos los dominios externos únicos de una página.
    Filtra: dominios internos, assets (cdn, fonts), redes sociales genéricas.
    """
    response = requests.get(source_url, timeout=30)
    soup = BeautifulSoup(response.content, 'html.parser')
    
    source_domain = urlparse(source_url).netloc
    external_domains = set()
    
    # Buscar en todos los enlaces
    for link in soup.find_all('a', href=True):
        href = link['href']
        if href.startswith('http'):
            domain = urlparse(href).netloc
            if domain and domain != source_domain:
                # Filtrar CDNs y assets comunes
                excluded = ['cdn.', 'fonts.', 'ajax.', 'facebook.com', 
                           'twitter.com', 'linkedin.com', 'instagram.com',
                           'youtube.com', 'google.com']
                if not any(ex in domain for ex in excluded):
                    external_domains.add(f"https://{domain}")
    
    return list(external_domains)
```

**Output esperado:**

```json
{
  "source_url": "https://firmsig.com/portfolio",
  "extracted_count": 47,
  "domains": ["https://firma1.com", "https://firma2.com", ...]
}
```

### 2. SCRAPING_ORCHESTRATOR

**Función:** Obtener contenido estructurado de cada sitio.

```python
def scrape_website(url):
    """
    Extrae contenido relevante para análisis.
    Páginas objetivo: Home, About, Services, Contact
    """
    pages_to_scrape = ['/', '/about', '/about-us', '/nosotros', 
                       '/services', '/servicios', '/practice-areas',
                       '/contact', '/contacto']
    
    site_data = {
        "url": url,
        "pages": {},
        "metadata": {},
        "assets": {}
    }
    
    for page in pages_to_scrape:
        try:
            full_url = url.rstrip('/') + page
            response = requests.get(full_url, timeout=15)
            if response.status_code == 200:
                soup = BeautifulSoup(response.content, 'html.parser')
                
                site_data["pages"][page] = {
                    "title": soup.title.string if soup.title else "",
                    "meta_description": soup.find('meta', {'name': 'description'}),
                    "h1": [h.text.strip() for h in soup.find_all('h1')],
                    "h2": [h.text.strip() for h in soup.find_all('h2')],
                    "paragraphs": [p.text.strip()[:500] for p in soup.find_all('p')[:10]],
                    "ctas": extract_ctas(soup),
                    "images_count": len(soup.find_all('img')),
                    "forms": len(soup.find_all('form'))
                }
        except:
            continue
    
    return site_data
```

#### 3.1 VISUAL_AESTHETICS_AGENT

```
ÁREAS DE EVALUACIÓN:
- Paleta de colores (coherencia, profesionalismo, sector legal)

CRITERIOS DE PUNTUACIÓN:
9-10: Diseño excepcional, líder en sector legal
7-8: Profesional y moderno, por encima del promedio
5-6: Adecuado pero genérico
3-4: Desactualizado, necesita refresh
1-2: Obsoleto, requiere rediseño total
```

#### 3.2 UX_NAVIGATION_AGENT

```
ÁREAS DE EVALUACIÓN:
- Arquitectura de información (profundidad, lógica)
- Efectividad de CTAs (visibilidad, contraste, texto)
- Flujo de conversión (pasos hasta contacto)
- Responsive design (inferido de estructura)
- Formularios (cantidad de campos, fricción)

MÉTRICAS CLAVE:
- Clicks hasta conversión: ideal ≤3
- Campos de formulario: ideal ≤5
- CTAs above-fold: mínimo 1
- Contraste de CTA: ≥4.5:1
```

#### 3.3 CONTENT_STORYTELLING_AGENT

```
ÁREAS DE EVALUACIÓN:
- Claridad de propuesta de valor (¿visible en 5 segundos?)
- Tono y voz de marca (formal, innovador, accesible)
- Prueba social (testimonios, casos, premios, rankings)
- Thought leadership (blog, publicaciones, insights)
- Credibilidad profesional (credenciales, experiencia)

PREGUNTAS CLAVE:
- ¿El visitante entiende qué hace la firma en 5 segundos?
- ¿Por qué elegirlos sobre la competencia?
- ¿Hay evidencia de resultados?
```

#### 3.4 TECHNICAL_PERFORMANCE_AGENT

```
ÁREAS DE EVALUACIÓN:
- Velocidad de carga (objetivo: <2.5s)
- SEO on-page (titles, metas, headers, URLs)
- Estructura de encabezados (H1 único, jerarquía correcta)
- Optimización de imágenes
- Schema markup (inferido)
- Mobile-friendliness (viewport, estructura)

HERRAMIENTAS A USAR:
- requests timing para velocidad
- BeautifulSoup para estructura
- Análisis de meta tags
```
